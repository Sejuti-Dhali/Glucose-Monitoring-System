## Software
- Synthetic optical data generation
- Random Forest reference implementation
- Local HTTP prediction API
- Simulated sensor readings

## Validation
Software tests must be executed successfully before
the implementation is considered verified.

## Important limitations
The cover illustration is conceptual, not a photograph
of an experimentally verified hardware assembly.

The synthetic dataset does not represent measurements
collected from the original apparatus.

The original report's numerical results are distinct
from the reconstructed software demonstration.

Physical Arduino, HC-05 Bluetooth and native Android
application functionality remain unverified.

The project is not intended for clinical diagnosis,
insulin dosing or medical decision-making.
