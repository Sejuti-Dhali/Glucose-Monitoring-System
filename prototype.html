05 / Interactive Software Prototype

Explore simulated optical glucose monitoring

A local Python API connects synthetic optical measurements with the trained Random Forest model and an interactive browser-based interface.

Live software demonstration

Checking local Python backend...

Demonstration only: The measurements are synthetic. No physical Arduino, HC-05 Bluetooth module or patient data is connected. The predictions are not suitable for medical decisions.

How the simulation works

Synthetic Sample → Six Absorbance Values → Python API → Random Forest → Displayed Prediction

The interactive prediction requires the Python backend running locally at http://127.0.0.1:8765. The public GitHub Pages website hosts static content and does not run the Python backend.

Local setup

From the repository root, run:

.\.venv\Scripts\python.exe software\backend\app.py

Then open:

http://127.0.0.1:8765/prototype.html
