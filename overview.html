01 / Project Overview

Research at the intersection of optics and AI

Optical Measurement

Six LEDs and phototransistors provide wavelength-specific measurements for optical analysis.

Embedded Acquisition

The documented prototype uses Arduino UNO and describes HC-05 Bluetooth communication.

Intelligent Prediction

Random Forest regression estimates glucose concentration; SHAP analysis supports model interpretation.

Research Scope

Experimental methodology and software reconstruction

The source report investigated prepared glucose solutions using a GOD-POD reagent and a multi-wavelength optical setup. This repository documents that methodology and provides newly written reference software.

Scientific transparency: The original experimental dataset and source code were not supplied. The executable demonstration uses synthetic data. The original reported results are presented separately from newly generated software demonstration results.
