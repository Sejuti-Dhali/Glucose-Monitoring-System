02 / System Architecture

From optical measurements to model prediction

The architecture separates optical acquisition, feature processing, machine-learning inference and application-level visualization.

Documented experimental workflow

Prepared Glucose Solution → LED Illumination → Phototransistor Response → Arduino UNO → Absorbance Features → Random Forest → Glucose Estimate
This diagram represents the reported conceptual workflow. The repository does not claim that the reconstructed software has been tested with the original physical device.

System components

Hardware

Arduino UNO, six LEDs, six phototransistors, resistors, optical chamber and HC-05 module.

Machine Learning

Six absorbance features, Random Forest regression, evaluation metrics and SHAP interpretation.

Application Layer

The original report describes an OpTose Android application. The repository includes a separate simulated browser interface.

Implemented software demonstration

Synthetic CSV → Python Random Forest → Local HTTP API → Browser Interface

This second pipeline is executable without physical hardware. It demonstrates software integration, not clinical validation or verified Bluetooth communication.
